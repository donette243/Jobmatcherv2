# JobMatcher

JobMatcher - это веб-приложение для анализа резюме, автоматического извлечения навыков пользователя, поиска вакансий и расчёта соответствия вакансий профилю пользователя.

## Возможности

* Регистрация пользователя
* Авторизация и аутентификация
* Управление профессиональным профилем
* Загрузка резюме в формате PDF или DOCX
* Автоматический анализ резюме
* Извлечение информации и навыков из резюме
* Просмотр вакансий
* Поиск вакансий
* Расчёт процента соответствия вакансии профилю
* Рекомендации вакансий на основе профиля пользователя
* REST API на FastAPI
* Веб-интерфейс на React

# Установка и запуск

## 1. Клонирование репозитория

git clone https://github.com/donette243/Jobmatcherv2.git
cd Jobmatcherv2

> Если проект находится в другом репозитории, необходимо использовать актуальный URL репозитория.

## 2. Настройка

Создать файл .env на основе файла .env.example.

В .env необходимо указать параметры подключения к базе данных и настройки аутентификации.

Файл .env не должен публиковаться в GitHub.

## 3. Запуск приложения через Docker

Из корневой директории проекта выполнить:


docker compose build
docker compose up


Docker запустит необходимые сервисы приложения, включая backend и базу данных.

## 4. Проверка работы приложения

После запуска открыть:

### Frontend


http://localhost:5173


### API


http://127.0.0.1:8000


### Документация API


http://127.0.0.1:8000/docs


Swagger позволяет просматривать и тестировать доступные API endpoints.


# Основной сценарий работы

После запуска приложения можно проверить полный сценарий:

1. Создать новый аккаунт.
2. Войти в аккаунт.
3. Перейти в Dashboard.
4. Заполнить профессиональный профиль.
5. Загрузить резюме в формате PDF или DOCX.
6. Проверить успешную обработку резюме.
7. Проверить автоматическое извлечение навыков из резюме.
8. Перейти к списку вакансий.
9. Выполнить поиск вакансий.
10. Перейти в раздел рекомендаций.
11. Проверить рассчитанный процент соответствия вакансий профилю.
12. Выйти из аккаунта.
13. Проверить, что защищённые страницы требуют авторизации.
14. Снова войти в аккаунт и проверить сохранность данных профиля.


# Тестирование

Для запуска backend-тестов выполнить:

pytest

Ожидаемый результат — все тесты должны завершиться успешно.

# Остановка приложения

Для остановки Docker-контейнеров:

docker compose down


После внесения изменений приложение можно пересобрать:


docker compose build
docker compose up


# Ожидаемый результат

После запуска пользователь должен получить доступ к веб-интерфейсу JobMatcher и иметь возможность пройти основной сценарий работы:

**Регистрация → Авторизация → Профиль → Загрузка CV → Извлечение навыков → Вакансии → Matching → Рекомендации**

API также доступен через Swagger для проверки работы отдельных endpoints.
