# JobMatcher

JobMatcher - это веб-приложение для анализа резюме, автоматического извлечения навыков пользователя, поиска вакансий и расчёта соответствия вакансий профилю пользователя.

## Возможности

* Регистрация пользователя
* Авторизация и аутентификация
* Управление профессиональным профилем
* Загрузка резюме в формате PDF или DOCX
* Автоматический анализ резюме
* Извлечение информации и навыков из резюме
* Просмотр вакансий
* Поиск вакансий
* Расчёт процента соответствия вакансии профилю
* Рекомендации вакансий на основе профиля пользователя
* REST API на FastAPI
* Веб-интерфейс на React

# Установка и запуск

## 1. Клонирование репозитория
git clone https://github.com/donette243/Jobmatcherv2.git
cd Jobmatcherv2

Если проект находится в другом репозитории, необходимо использовать актуальный URL репозитория.

## 2. Настройка Backend

Перейти в директорию backend:

cd backend

Создать виртуальное окружение:

python -m venv .venv

Активировать виртуальное окружение.

Windows CMD
.venv\Scripts\activate
Windows PowerShell
.\.venv\Scripts\Activate.ps1

После активации в начале строки терминала должно появиться:

(.venv)
## 3. Установка зависимостей Backend

Установить зависимости проекта:

pip install -r requirements.txt

Для запуска приложения также необходимы следующие зависимости:

pip install email-validator
pip install "pyjwt>=2.13.0"
pip install "pwdlib[argon2]>=0.3.0"
pip install "aiofiles>=25.1.0"
pip install "alembic>=1.18.5"
pip install "uvicorn>=0.52.1"

email-validator необходим для использования EmailStr в Pydantic.

PyJWT используется для JWT-аутентификации.

pwdlib[argon2] используется для хеширования паролей.

aiofiles используется для работы с загружаемыми файлами.

Alembic используется для миграций базы данных.

## 4. Настройка переменных окружения

Создать файл .env на основе файла .env.example.

В .env необходимо указать параметры подключения к базе данных, настройки JWT и, при необходимости, настройки SMTP для восстановления пароля.

Пример структуры:

DATABASE_URL=...
JWT_SECRET_KEY=...
JWT_ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60

SMTP_HOST=...
SMTP_PORT=587
SMTP_USER=...
SMTP_PASSWORD=...
SMTP_FROM=...
FRONTEND_URL=http://localhost:5173

Значения секретных параметров необходимо указать самостоятельно.

Файл .env не должен публиковаться в GitHub.

## 5. Миграции базы данных

Перед первым запуском необходимо применить миграции:

alembic upgrade head

Миграции создают и обновляют структуру базы данных.

## 6. Запуск Backend

В Windows CMD необходимо указать путь к директории src:

set PYTHONPATH=src

После этого запустить сервер:

uvicorn jobmatcher.main:app --reload

При успешном запуске должно появиться:

Uvicorn running on http://127.0.0.1:8000
Application startup complete.

Backend API будет доступен по адресу:

http://127.0.0.1:8000

Документация Swagger:

http://127.0.0.1:8000/docs

Backend необходимо оставить запущенным во время работы frontend.

## 7. Настройка Frontend

Открыть новый терминал.

Перейти в директорию frontend:

cd Jobmatcherv2/frontend

Установить зависимости:

npm install

Запустить frontend:

npm run dev

После успешного запуска frontend будет доступен по адресу:

http://localhost:5173
## 8. Проверка работы приложения

После запуска backend и frontend открыть:

Frontend
http://localhost:5173
API
http://127.0.0.1:8000
Документация API
http://127.0.0.1:8000/docs

Swagger позволяет просматривать и тестировать доступные API endpoints.

## 9. Основной сценарий работы

После запуска приложения можно проверить полный сценарий:

Создать новый аккаунт.
Войти в аккаунт.
Перейти в Dashboard.
Заполнить профессиональный профиль.
Загрузить резюме в формате PDF или DOCX.
Проверить успешную обработку резюме.
Проверить автоматическое извлечение навыков из резюме.
Перейти к списку вакансий.
Выполнить поиск вакансий.
Перейти в раздел рекомендаций.
Проверить рассчитанный процент соответствия вакансий профилю.
Выйти из аккаунта.
Проверить, что защищённые страницы требуют авторизации.
Снова войти в аккаунт и проверить сохранность данных профиля.
## 10. Восстановление пароля

Приложение поддерживает восстановление пароля.

Основной сценарий:

Перейти на страницу авторизации.
Нажать «Забыли пароль?».
Указать email зарегистрированного пользователя.
Получить письмо для восстановления пароля.
Перейти по ссылке из письма.
Указать новый пароль.
После успешного изменения пароля войти с новым паролем.

Токен восстановления имеет ограниченный срок действия.

## 11. Тестирование

Для запуска backend-тестов:

pytest

Тесты проверяют основные компоненты обработки CV, профиля, вакансий и matching.

Ожидаемый результат:

5 passed
## 12. Запуск приложения через Docker

Из корневой директории проекта выполнить:

docker compose build
docker compose up

Docker запустит необходимые сервисы приложения, включая backend и базу данных.

Для остановки Docker-контейнеров:

docker compose down

После внесения изменений приложение можно пересобрать:

docker compose build
docker compose up

## 13. Ожидаемый результат

После запуска пользователь должен получить доступ к веб-интерфейсу JobMatcher и иметь возможность пройти основной сценарий:

Регистрация → Авторизация → Профиль → Загрузка CV → Извлечение навыков → Вакансии → Matching → Рекомендации

Также доступно восстановление пароля:

Забыли пароль → Email → Ссылка восстановления → Новый пароль → Авторизация

API доступен через Swagger для проверки отдельных endpoints.
